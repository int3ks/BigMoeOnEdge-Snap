# BigMoeOnEdge² Wiki

BigMoeOnEdge² runs large GGUF models (including Mixture-of-Experts models bigger than the phone's RAM) locally on
Android, with chat, tools, a workspace, a local API server and – new – an agent that runs real commands through Termux.

## Pages

* **[Agent mode with Termux](Agent-mode-with-Termux)** – setup, how the agent works, live status and cancel, approval
  and safety, grammar-checked tool calls, model and KV cache tips, examples and troubleshooting.
